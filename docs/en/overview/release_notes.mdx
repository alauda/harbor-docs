## v2.14.6

### Features and Enhancements

#### Upgrade Harbor to v2.14.6

The bundled Harbor is upgraded to v2.14.6. After the operator is upgraded, instances running Harbor v2.14.x are upgraded to v2.14.6 automatically. Instances running Harbor v2.12.x must be upgraded manually: upgrade PostgreSQL to version 15 or 16 and back up the instance first, and expect the instance to be unavailable during the upgrade.

#### Product Renamed to Alauda Toolchain Enterprise Registry E1

The operator is renamed from Alauda Build of Harbor to Alauda Toolchain Enterprise Registry E1. The new name is shown in OperatorHub and in the console.

#### Single High Availability Template

The `High Availability (Envoy Gateway)` template is removed and merged into the `High Availability` template. To expose a new instance through Envoy Gateway, use the `High Availability` template and set `Network Access` to `Gateway API`. See [Expose Harbor with Envoy Gateway](../howto/11_expose_with_envoy_gateway.mdx).

#### Migrate from Ingress to Gateway API

A new guide describes how to switch an existing instance from Ingress to Gateway API, including verification and rollback. See [Migrate a Harbor Instance from Ingress to Gateway API](../howto/12_migrate_ingress_to_gateway.mdx).

#### Fix Security Vulnerabilities

With this release, several security vulnerabilities have been fixed.
